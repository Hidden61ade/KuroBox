# 关卡工坊

正式制作入口在 Godot 4.6 顶部的 **KuroBox** 主屏，关卡库、Inspector 参数和发布流程见 [原生工作台](native_workbench.md)。本文说明共享绘制控件，以及游戏菜单和 `features/editor/editor.tscn` 的单关 F6 入口；三者使用同一套关卡格式与试玩规则。

先选择图块，再在棋盘上绘制。地板、墙、目标格、出生点与物件分层存储；右键只擦除当前选择的层。删除地板不会擅自删除上面的内容，检查面板会指出留下的非法位置。宽高范围为 4–24 格，缩小时裁去越界内容并给出提示，一次撤销可以完整恢复。

画笔 B、擦除 E、矩形 R、填充 F、框选 S、移动 M、粘贴 V。填充只用于地板、墙和目标格，范围是当前图层上相同状态的四连通区域。画笔的一次拖动、一次矩形、一次填充都算一个撤销步骤；Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。

框选后点“复制选区”，切到粘贴工具，点击目标区域的左上角。复制包含各层内容，复制出的物件会取得新实例 ID，选区内部的机关连线也会映射到新实例。出生点全关卡只有一个，粘贴包含出生点的选区会移动出生点。移动选区保持原实例 ID；目标区域被整个替换，空格也会覆盖，移动前后均可撤销。超出地图的复制或移动会整笔拒绝，不会留下半个选区。

物件图块从 `ObjectCatalog` 读取。新增类型登记后会自动出现在面板中；行为仍由对应规则实现负责。框选或绘制后可在属性区查看实例。压力板可点“连线到门”，再点击棋盘上的门，重复点击即可断开；也能直接在属性区勾选目标门。连线以实例 ID 保存，删除门时同时清理引用。箱子和压力板属于不同物件层，可放在同一格；两个实体或两个装置不能通过画笔无意堆叠。放置不合法的组合仍由统一校验指出。

导入、导出使用 `.kuro.json` 或 `.json`。导出前、测试前调用与正式关卡相同的 `LevelCodec.validate`，检查坐标、引用和结构；检查通过只表示可以加载，不证明谜题可解。报错含实例或坐标时，点击列表可在棋盘上定位。导入文件无效时保留当前文档，不用空白关卡覆盖已有编辑。

“测试”或 F5 将文档深拷贝给正式 `BoardState`。从测试返回时保留画笔、选区和当前文档，试玩中箱子、机关与角色的变化不会写回关卡。独立 F6 模式也提供方向键 / WASD、Space 出拳、Z 撤销、R 重开和 Esc 返回编辑。

标题供玩家查看，关卡 ID 供存档和引用使用。更换标题无需修改 ID。尺寸、标题、出生朝向、物件、连线等修改均可撤销。导入关卡中的解法记录属于原始版本，编辑后会清空，避免将旧解法作为新关卡的可解证明。离开、新建或导入前，若文档相对上一次导出仍有修改，会询问是否丢弃。圆点表示尚未导出；文件成功写入后才清除。

编辑器不承担求解器、通用脚本编排或引擎资产管理职责。内容作者使用图块和参数；规则程序扩展物件行为；美术和音频调整类型的表现映射。保存文件只包含关卡初始定义，编辑选区、撤销历史和测试状态均不写入关卡。
